# Условия Лауэ

## Постановка

Плоская монохроматическая волна с волновым вектором $\vec{k}_0$ падает на кристалл с периодической решёткой (векторы трансляции $\vec{a}_1,\vec{a}_2,\vec{a}_3$). Условие дифракции — конструктивная интерференция рассеянных волн.

## Условия Лауэ (векторная форма)

Рассеянная волна с волновым вектором $\vec{k}$ (упругое рассеяние: $|\vec{k}|=|\vec{k}_0|=2\pi/\lambda$) даёт дифракционный максимум, если для всех трёх базисных векторов:

$$\vec{k}-\vec{k}_0 = 2\pi\,\vec{G}, \qquad \vec{G} = h\,\vec{b}_1 + k\,\vec{b}_2 + l\,\vec{b}_3$$

Или через приращение волнового вектора $\Delta\vec{k}=\vec{k}-\vec{k}_0$:

$$\Delta\vec{k}\cdot\vec{a}_i = 2\pi h_i, \quad h_i \in \mathbb{Z} \quad (i=1,2,3)$$

## Скалярная форма (уравнения Лауэ)

$$\begin{cases} a_1(\cos\alpha - \cos\alpha_0) = h\lambda \\ a_2(\cos\beta - \cos\beta_0) = k\lambda \\ a_3(\cos\gamma - \cos\gamma_0) = l\lambda \end{cases}$$

где $\alpha_0,\beta_0,\gamma_0$ — направляющие косинусы $\vec{k}_0$; $\alpha,\beta,\gamma$ — то же для $\vec{k}$.

## Эквивалентность условию Вульфа–Брэгга

Условия Лауэ эквивалентны уравнению Вульфа–Брэгга на семействе плоскостей $(hkl)$:

$$2d_{hkl}\sin\theta = n\lambda$$

## Таблица

| Величина | Смысл |
|---|---|
| $\vec{a}_i$ | базисные векторы решётки (прямое пространство) |
| $\vec{b}_i$ | векторы обратной решётки, $\vec{a}_i\cdot\vec{b}_j = 2\pi\delta_{ij}$ |
| $\vec{G}$ | вектор обратной решётки, индексы $(hkl)$ |
| $\Delta\vec{k}$ | передача импульса; лежит в обратной решётке |

## Условие существования решения

Три уравнения Лауэ + условие упругости $|\vec{k}|=|\vec{k}_0|$ переопределяют систему: при заданной $\lambda$ и ориентации кристалла решение о направлении $\vec{k}$ существует лишь для специальных ориентаций (метод Лауэ) либо при варьировании $\lambda$ (метод порошка).
