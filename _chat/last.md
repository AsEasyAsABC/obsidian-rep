**> какой минимальный объем памяти необходим для работы**

Минимум по факту — не по ёмкости, а по содержимому:

**Ёмкость:** формально любая microSD ≥ 128 МБ (FAT16/FAT32). Практически бери **≥ 1 ГБ** — меньше почти не встретишь, и нет смысла искать.

**Сколько реально занимает прошивка + конфиги:**

| Компонент | Размер |
|---|---|
| `Duet2CombinedFirmware.bin` (в `sys/` при обновлении) | ~500 КБ |
| `sys/` (config.g, homing, mesh, macros) | ~50–200 КБ |
| `www/` (Duet Web Control) | ~2–4 МБ |
| `gcodes/` | зависит от печати, обычно пусто |
| `filaments/`, `macros/` | КБ |

Итого система занимает **< 5 МБ**. Всё остальное — под G-code файлы.

**Ограничения по максимуму, а не минимуму** (частая путаница):
- **≤ 32 ГБ** (SDHC, FAT32). SDXC (>32 ГБ) Duet 2 официально не поддерживает — контроллер не всегда монтирует.
- Файловая система FAT32; для 32 ГБ Windows форматирует только через SD Card Formatter или `mkfs.vfat`.

Практический ответ: **любая microSD 1–32 ГБ, FAT32**. Если карту используешь только для прошивки/конфигов — 1–8 ГБ с запасом.
